# Fitness Arcade 🕹️👟

An '80s-themed running tracker: daily run goal, high scores, PR wall, shoe mileage, virtual journeys, ghost runner, weight and water vs Diet Coke. Open it on your phone and use **Add to Home Screen**.

- Everything you log stays in your browser on your device (localStorage). Nothing is uploaded.
- Online extra: run-weather tips from Open-Meteo.
- Fonts: Press Start 2P and Monoton (SIL Open Font License), embedded in `index.html`.
